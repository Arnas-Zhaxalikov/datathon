# Qamqor AI — веб-приложение

STAT.DATATHON-2026, трек AI for Official Statistics. Приложение показывает, кого не видит
официальное определение бедности и что изменит та или иная мера поддержки.

**Главный принцип: каждое число считает расчётное ядро** (`qamqor/` в корне репозитория).
Приложение ничего не считает само: сервер передаёт анкету в ядро и раскладывает его ответ для
экрана, а ИИ-ассистент только вызывает инструменты ядра и объясняет результат.

## Установка

```bash
cd agent/backend
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# впишите в .env свой ANTHROPIC_API_KEY — нужен только для вкладки «Для анализа»
```

## Запуск

```bash
uvicorn app:app --reload --port 8000
```

Откройте http://localhost:8000. Таблица домохозяйств для ядра лежит в `qamqor/out/households.csv`.

## Три раздела

**Моя семья** — калькулятор для гражданина: состав семьи, доход и регион (по желанию — заработок
и тип занятости главного кормильца, пенсии и пособия, расходы на жильё). Показывает уровень на
карте доходов A–E, положение относительно черты АСП и прожиточного минимума региона, четыре
стресс-теста с ползунками и формулами, блок «А что, если» и сравнение с выборкой. Считает
`engine.check_household`. Работает **без ключа API**.

**Обзор по стране** — доли людей по уровням A–E и таблица регионов. Данные — инструменты ядра
`gap_overview` и `simulate` с разбивкой по регионам. Тоже без ключа.

**Для анализа (ИИ)** — чат. Claude Sonnet 5.5 вызывает пять инструментов ядра (`gap_overview`,
`simulate`, `compare_policies`, `check_household` и `explain`), получает готовые числа и объясняет
их; под каждым ответом видно, какие расчёты были вызваны. `explain` ничего не считает: он читает
граф правил и происхождения цифр (`qamqor/results/graph.json`) и отвечает на вопросы «откуда эта
цифра» и «почему семье не положена помощь». Данных модель не видит и кода не выполняет.
Нужен `ANTHROPIC_API_KEY`; без ключа раздел отвечает понятной ошибкой 503.

## Как устроено

| Файл | Что делает |
|---|---|
| `backend/core.py` | Мост к ядру: анкета → `engine.check_household`, ответы ядра → вид для экрана. Формул нет |
| `backend/app.py` | FastAPI: `/api/regions`, `/api/summary`, `/api/classify`, `/api/chat` |
| `backend/claude_agent.py` | Ассистент: системные правила и цикл вызова инструментов |
| `backend/test_core.py` | Проверка моста: `python test_core.py` |
| `web/` | Интерфейс: три языка, светлая и тёмная тема, графики в ответах чата |

Уровни, стресс-тесты, источники прожиточного минимума и ограничения данных описаны в
`qamqor/README.md`; итоговые числа — в `qamqor/results/final_tables.md`.

**Допущения формы «Моя семья»** показываются на экране. Если заработок главного кормильца не
указан, берётся 66% дохода семьи, делённые на число работающих (или доход без пенсий и пособий,
если они указаны). Если не указаны расходы на жильё и коммунальные — 12,5% дохода семьи.

**Сравнение с выборкой** («среди людей в семьях с таким же числом детей в регионе») показывается
только при 30 и более семьях в ячейке.

## Известные ограничения

- Ответ чата приходит целиком, без построчного вывода.
- Сессии чата хранятся в памяти процесса — перезапуск сервера их сбрасывает.
- Только локальный запуск. Перед публикацией в сети нужно закрыть чат паролем или лимитом
  запросов (каждый вопрос тратит средства с ключа) и сузить список разрешённых источников запросов.
