# Qamqor AI — локальный запуск

STAT.DATATHON-2026, трек AI for Official Statistics. Qamqor AI находит
домохозяйства, которых не видит официальная статистика бедности, и
показывает, что изменит та или иная мера поддержки.

## Установка

```bash
cd agent/backend
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# впишите в .env свой ANTHROPIC_API_KEY — нужен только для вкладки "Для анализа"
```

## Запуск

```bash
uvicorn app:app --reload --port 8000
```

Откройте http://localhost:8000. Перед первым запуском должна быть посчитана
`outputs/households_2021_2024.parquet` (шаги 1–3 корневого конвейера, см.
корневой README) — `agent/backend/segmentation.py` считает поверх неё.

## Три режима в интерфейсе

**Моя семья** — калькулятор для гражданина: вводите состав семьи, доход и
регион (по желанию — заработок кормильца, пенсии и пособия, расходы на
жильё), получаете статус, шкалу с положением дохода относительно черты АСП
и минимума региона, три сценария с ползунками и формулами, вывод по
статусу, блок «А что, если» и сравнение с выборкой. Работает **без ключа
API** — чистый детерминированный расчёт.

**Обзор по стране** — те же четыре статуса по всем 11 948 домохозяйствам
2024 года, каждое — относительно минимума своего региона, плюс таблица по
регионам. Тоже без ключа.

**Для анализа (ИИ)** — чат-режим, Claude Sonnet 5.5 с `code_execution`
поверх агрегатов и `docs/RULES.md`, с гейтом качества на Haiku 4.5.
Единственная вкладка, которой нужен `ANTHROPIC_API_KEY`; без ключа отвечает
понятной ошибкой 503, не роняя остальной интерфейс.

## Методология (`agent/backend/engine.py`)

Все формулы — в `engine.py`: словарь минимумов `REGIONS`/`REGIONAL_SM`,
`check_household(..., region=...)`, три сценария. `segmentation.py` применяет
те же функции к выборке, интерфейс только показывает результат. Проверка:
`python agent/backend/test_engine.py`.

Статусы — по доходу на человека в месяц относительно минимума своего региона:
- **A** — доход ниже черты адресной помощи (АСП)
- **B** — доход ниже прожиточного минимума, выше черты АСП
- **C** — доход выше минимума, но хотя бы один из трёх сценариев опускает
  его ниже
- **D** — доход выше минимума во всех трёх сценариях

**Прожиточный минимум — по регионам.** Используется фактический ПМ по
регионам, 2024, приближённо: соотношения регионов по данным БНС за
июль–август 2024, приведённые к среднегодовому значению по стране 51 058 тг.
Значения лежат в одном словаре `engine.REGIONS` рядом с названиями регионов
(20 регионов; Астана, Алматы и Шымкент — отдельно). Черта АСП = 70% от
минимума региона. Итог по стране на вкладке «Обзор» — сумма по регионам,
поэтому статус семьи на обеих вкладках считается одинаково. Минимумы есть
только за 2024 год, поэтому и расчёт доступен только за 2024-й.

**Относительная черта бедности** (50% медианного дохода на человека по
выборке) оставлена отдельным справочным показателем. Она отражает уровень
доходов, а не стоимость жизни, и как прожиточный минимум нигде не
подписывается.

**Сценарии** (параметры N, X, Y меняются ползунками, по умолчанию 3, 15, 30):
- кормилец N месяцев без заработка: в среднем за год
  `(доход*12 − заработок*N) / 12 / размер семьи`, в месяцы без заработка
  `(доход − заработок) / размер семьи`;
- доход падает на X%: `доход*(1 − X/100) / размер семьи`;
- жильё и коммунальные дорожают на Y%: `(доход − расходы*Y/100) / размер семьи`.

**Допущения для пустых полей** показываются на экране: заработок кормильца —
66% дохода, делённые на число работающих (или доход без пенсий и пособий,
если они указаны); жильё и коммунальные — 12,5% дохода. Для строк выборки:
заработок кормильца — зарплата домохозяйства на одного работающего, жильё и
коммунальные — 25% расходов.

**Сравнение с выборкой** («среди семей с таким же числом детей в регионе»)
показывается только при 30 и более семьях в ячейке.

**Данные месячные, не годовые.** `income_total`/`spend_total` в
`households_2021_2024.parquet` — ГОДОВЫЕ суммы (проверено по
`outputs/aggregates/m_totals_by_year.csv`). Ранняя версия модуля не делила
на 12 и получала черту бедности в 12 раз выше реальной — исправлено и
перепроверено до коммита.

## Известные ограничения MVP

- Чат-режим не стримится токен за токеном — ждём полный ответ (см. ниже
  про server-side `code_execution`).
- Сессии чата хранятся в памяти процесса — перезапуск сервера их сбрасывает.
- Только локальный запуск, без хостинга (решение команды под защиту на
  своём ноутбуке).
