# Qamqor AI — локальный запуск

STAT.DATATHON-2026, трек AI for Official Statistics. Qamqor AI находит
домохозяйства, которых не видит официальная статистика бедности, и
показывает, что изменит та или иная мера поддержки.

## Установка

```bash
cd agent/backend
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# впишите в .env свой ANTHROPIC_API_KEY — нужен только для вкладки "Для анализа"
```

## Запуск

```bash
uvicorn app:app --reload --port 8000
```

Откройте http://localhost:8000. Перед первым запуском должна быть посчитана
`outputs/households_2021_2024.parquet` (шаги 1–3 корневого конвейера, см.
корневой README) — `agent/backend/segmentation.py` считает поверх неё.

## Три режима в интерфейсе

**Моя семья** — калькулятор для гражданина: вводите состав семьи и доход,
получаете группу (A/B/C/D) и метр с позицией дохода относительно черты АСП
и прожиточного минимума, плюс результат трёх стресс-сценариев (потеря
кормильца, доход −15%, коммунальные +30%). Работает **без ключа API** —
чистый детерминированный расчёт, кэшируется в памяти процесса (~1.4с на
первый запрос, ~15мс дальше).

**Обзор по стране** — те же четыре группы агрегированно по всем 11 948
домохозяйствам 2024 года. Тоже без ключа.

**Для анализа (ИИ)** — чат-режим, Claude Sonnet 5.5 с `code_execution`
поверх агрегатов и `docs/RULES.md`, с гейтом качества на Haiku 4.5.
Единственная вкладка, которой нужен `ANTHROPIC_API_KEY`; без ключа отвечает
понятной ошибкой 503, не роняя остальной интерфейс.

## Методология сегментации (`agent/backend/segmentation.py`)

Группы:
- **A** — доход на душу ниже черты АСП (уже имеет право на помощь)
- **B** — ниже прожиточного минимума, но выше черты АСП — **бедны, но не
  видны системе**
- **C** — выше прожиточного минимума сейчас, но падает ниже него хотя бы в
  одном из трёх стресс-сценариев — **скрыто уязвимы**
- **D** — устойчивы во всех сценариях

**Важно про черту бедности.** Официального прожиточного минимума БНС у нас
нет, и подставлять непроверенную "официальную" цифру в тенге означало бы
выдавать предположение за факт — нарушение собственного `docs/RULES.md`.
Вместо этого используется относительная черта (стандартная методология
OECD/Eurostat): 50% медианного дохода на душу по году, черта АСП — 70% от
неё. Явно задокументировано в коде и в интерфейсе, не выдаётся за
официальный показатель.

**Данные месячные, не годовые.** `income_total`/`spend_total` в
`households_2021_2024.parquet` — ГОДОВЫЕ суммы (проверено по
`outputs/aggregates/m_totals_by_year.csv`). Ранняя версия модуля не делила
на 12 и получала черту бедности в 12 раз выше реальной — исправлено и
перепроверено до коммита.

**Стресс-сценарии** — упрощённые, задокументированы как приближения в
коде: потеря кормильца снижает только зарплатную часть дохода
(`income_wage`) пропорционально доле одного занятого, не весь доход
(ранняя версия ошибочно обнуляла доход целиком однодоходным семьям —
исправлено).

## Известные ограничения MVP

- Чат-режим не стримится токен за токеном — ждём полный ответ (см. ниже
  про server-side `code_execution`).
- Сессии чата хранятся в памяти процесса — перезапуск сервера их сбрасывает.
- Только локальный запуск, без хостинга (решение команды под защиту на
  своём ноутбуке).
