# ИИ-аналитик — локальный запуск

Слой 2 ИИ-аналитика (STAT.DATATHON-2026, трек AI for Official Statistics):
Claude Sonnet 5.5 с `code_execution` поверх выгруженных агрегатов, плюс
гейт качества на Haiku 4.5, проверяющий каждый ответ против `docs/RULES.md`.

## Установка

```bash
cd agent/backend
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
# впишите в .env свой ANTHROPIC_API_KEY
```

## Запуск

```bash
uvicorn app:app --reload --port 8000
```

Откройте http://localhost:8000 — интерфейс в стиле ChatGPT, без сборки
фронтенда (чистые HTML/CSS/JS, отдаются тем же сервером через `StaticFiles`).

Перед первым запуском должны быть посчитаны `outputs/households_2021_2024.csv`
и `outputs/aggregates/*` (шаги 1–8 конвейера, см. корневой README) — агент
выгружает именно эти файлы, не сырой архив организатора.

## Как это работает

1. При первом сообщении сессии бэкенд выгружает `households_2021_2024.csv`,
   все `outputs/aggregates/*.csv` и `data_quality_flags.json` в песочницу
   `code_execution` (Anthropic-hosted). В рамках той же сессии контейнер
   переиспользуется через `container_id` — повторной выгрузки не происходит.
2. Системный промпт — это `docs/RULES.md` целиком: агент обязан свериться
   с дрейфом схемы, надёжностью корреляций и заполненностью перед тем, как
   сделать содержательное утверждение.
3. После ответа Sonnet второй, дешёвый вызов (Haiku 4.5) проверяет его
   против чек-листа из пяти правил и возвращает structured output — это
   и есть чипы ✓/✗ под каждым ответом в интерфейсе. Гейт не блокирует
   ответ: он показывает механизм вживую, а не прячет его.

## Известные ограничения MVP

- Ответ не стримится токен за токеном — бэкенд ждёт полный ответ. Это
  осознанный компромисс ради надёжности демо в сжатые сроки: совмещать
  SSE-стриминг с server-side `code_execution` и вторым вызовом-гейтом —
  отдельная задача, не критичная для защиты.
- Сессии хранятся в памяти процесса — перезапуск сервера их сбрасывает.
- Только локальный запуск, без хостинга (сознательное решение команды
  под защиту на своём ноутбуке, без рисков с сетью на площадке).
